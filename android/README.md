# AirPlayr — Native Android

This directory is the complete Android application project for AirPlayr.

## Runtime
- Kotlin
- Jetpack Compose + Material 3
- AndroidX Navigation
- AndroidX Room
- AndroidX DataStore
- AndroidX WorkManager
- AndroidX Media3 / ExoPlayer / MediaSession
- Android MediaStore + Storage Access Framework
- Google Cast through Media3 Cast

## Build
Open this `android` directory as the Gradle project in Android Studio, or run:

```bash
./gradlew :app:assembleDebug
```

The application id is `com.airplayr.app`.
